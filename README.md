## Overview

CharacterForge Pro is a browser-based character design studio. Browse 50+ templates across fantasy, sci-fi, modern, and historical genres, then tune every detail with precision controls. Every slider nudge, color pick, and toggle updates the canvas instantly — no save button, no loading spinner.

---

## Features

### Start from anywhere

Browse 50+ templates across multiple genres — Cartoon, Fantasy, Sci-Fi, Modern, Historical, and more. Each template comes with hand-tuned layers, color zones, and part visibility presets, ready to remix into something completely your own.

### See it happen, instantly

Every slider nudge, color pick, and toggle redraws the canvas in under 100ms. No save button, no loading spinner — just you and your character, live. Pan, zoom, and reset with intuitive canvas controls.

### Tune every atom

Precise controls for hair, eyes, skin, outfit, and accessories. Sliders, color swatches, toggles, and combo boxes — grouped by body part so you never hunt for a setting. Template-specific controls appear automatically based on the character you're editing.

### Click on the canvas to select

Click any part of the character on the canvas and the corresponding control panel tab activates automatically. Click the head → hair/face controls. Click the body → clothing controls. Intuitive, fast, and visual.

### Full undo history

Made a change you don't like? Undo and redo through your entire session. Every modification is tracked, so you can experiment freely without fear.

### Dark & light mode

Seamless dark and light themes with persistent preference. Toggle with a single click — the entire interface adapts, from canvas background to color pickers.

### Export in any format

Download your character as PNG, SVG, WebP, or JPEG at resolutions up to 4K. Need a transparent headshot? A full-body sprite sheet? One click, done.

### URL sharing

Share your character with a link. Every customization — template choice, colors, sliders, toggles — is encoded in the URL. Send a link, and the recipient sees exactly what you created.

### Keyboard shortcuts

Power-user shortcuts for undo, redo, reset view, toggle panels, and more. No need to reach for the mouse for common actions.

## Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Open in your browser
open http://localhost:3000
```

Build for production:

```bash
npm run build
npm start
```
