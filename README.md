## ✨ Overview

**CharacterForge Pro** is a browser-based character design studio. Browse 50+ templates across multiple genres, then tune every detail with precision controls. Every slider nudge, color pick, and toggle updates the canvas instantly — no save button, no loading spinner.

<br />

## 🎯 Features

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>🎨 Start from Anywhere</h3>
      <p>Browse 10+ templates across <strong>Cartoon, Fantasy, Sci-Fi, Modern, and Historical</strong> genres. Each template comes with hand-tuned layers, color zones, and part visibility presets, ready to remix into something completely your own.</p>
    </td>
    <td width="50%" valign="top">
      <h3>⚡ See It Happen, Instantly</h3>
      <p>Every slider nudge, color pick, and toggle redraws the canvas in <strong>under 100ms</strong>. No save button, no loading spinner — just you and your character, live. Pan, zoom, and reset with intuitive canvas controls.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>🔧 Tune Every Atom</h3>
      <p>Precise controls for hair, eyes, skin, outfit, and accessories. Sliders, color swatches, toggles, and combo boxes — grouped by body part. <strong>Template-specific controls</strong> appear automatically based on the character you're editing.</p>
    </td>
    <td width="50%" valign="top">
      <h3>👆 Click on the Canvas</h3>
      <p>Click any part of the character and the <strong>corresponding control tab activates</strong> automatically. Click the head → hair/face controls. Click the body → clothing controls. Intuitive, fast, and visual.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>↩️ Full Undo History</h3>

    </td>
    <td width="50%" valign="top">
      <h3>🌓 Dark & Light Mode</h3>
      <p>Seamless dark and light themes with <strong>persistent preference</strong>. Toggle with a single click — the entire interface adapts, from canvas background to color pickers.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>📥 Export in Any Format</h3>

      <h3>🔗 URL Sharing</h3>

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open in your browser
open http://localhost:3000
```

<br />

## 📦 Project Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server (Next.js with Turbopack) |
| `npm run build` | Build for production |
| `npm start` | Start production server |
| `npm run test` | Run full test suite (Vitest) |
| `npm run lint` | Run ESLint across the project |
| `npx tsc --noEmit` | Type-check without emitting files |

<br />

## 🏗️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Framework** | Next.js 16 (App Router) |
| **UI** | React 19 |
| **State** | Zustand + zundo (undo/redo) |
| **Styling** | Tailwind CSS v4 |
| **Rendering** | Canvas 2D API + SVG composition |
| **Testing** | Vitest + Testing Library |
