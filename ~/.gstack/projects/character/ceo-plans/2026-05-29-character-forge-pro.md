## Vision

### 10x Check
The character creator space is crowded with tools that are either shallow (Ready Player Me) or cluttered and confusing (Picrew's inconsistent UX, Hero Forge's deep nested menus). The 10x version of CharacterForge Pro is: a character creator that feels like a creative tool, not a spreadsheet with sliders. It has the depth of Hero Forge but the polish of a well-designed app. Users open it, pick a style, and immediately start tweaking — every control is discoverable, every change is reversible (undo/redo), and the result looks good enough to share without editing.

The 10x check: undo/redo is a massive UX moat — no major competitor has proper undo/redo. Real-time canvas preview + clear hierarchical controls + persistent character state = the combination no existing tool delivers well. The share URL feature turns this from a solo tool into a viral loop — users share their character link, others open it and click "Remix this."

### Dream State
"It's the most flexible." A user can change anything they want to see changed — body proportions, facial features, clothing layers, colors, accessories — all without friction. The tool gets out of the way and lets the user feel like the creator.

- Character gallery section on landing page showing 4-6 rendered character examples

- Export presets: "Social" (square, 1080×1080 JPEG), "Profile Pic" (500×500 PNG transparent), "Full Body" (original size PNG transparent)
- First-run onboarding: 3-4 contextual tooltips highlighting category selection, canvas controls, undo/redo, and export
- Dev-only usage analytics: track most-used controls, time spent per category, abandonment points. No PII.
- Dark/light mode toggle in top bar, persisted in localStorage

## Key Strategic Decisions
- **Premise**: Cleaner UX differentiator — existing creators are cluttered or shallow
- **Build approach**: Vertically integrated — ship 1-2 categories (Cartoon + 1 more) fully loaded
- **Asset pipeline**: Open-source CC0/SVG game asset packs (not building SVGs from scratch)
- **Business model**: Free tool (portfolio/showcase project)
- **Open source**: After Phase 1 launch
- **3D**: Aspirational — keep architecture modular but no WebGL dependency in Phase 1
- **Competitive moat**: Undo/redo is unique in this space. Real-time canvas + clear controls + share links compound the advantage.

## Landscape Validation
- **Picrew**: Largest library (10k+ creator-made templates), but no undo, inconsistent UI across creators, no real-time preview
- **Hero Forge**: Deep customization (tabletop minis), but nested menus, complex pose controls, paid model
- **Doll Divine/Rinmaru**: Fixed layering, rigid templates, Flash legacy
- **Ready Player Me**: Sleek but shallow — avatar for metaverse, not creative expression
- **Our edge**: Undo/redo + real-time canvas + clean hierarchical controls + deep customization + free + share URLs
